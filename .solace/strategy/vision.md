Solace is an agentic development environment. It wraps a software project & mediates all work on it: AI agents handle engineering tasks; humans set direction, answer agents' questions & approve results. Agents change the project only through Solace, & the human assigns, follows & reviews agents' work through the app without reading code nor using CLI. Solace provides guardrails but also increases the focus and effectiveness of weaker models. Its commands are clearly documented & offer 1 way to do anything. Solace must be frictionless to use on other PCs and projects. 

Project code is kept in a store of symbols (e.g. functions), each with a permanent ID. Agents read & change code by symbol, & every change is type-checked; code with errors is not saved. Solace writes ordinary source files from the store for the normal compiler & test runner. It reaches the project's other files through Solace. Changes associated with each task are recorded so the work can be reviewed and undone.
